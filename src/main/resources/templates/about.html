About This Application

A demonstration of modern Spring Boot development with beautiful Thymeleaf templates and PostgreSQL persistence.

Features

What's Included

A complete full-stack CRUD application

🗄️
PostgreSQL Database

Persistent data storage with Spring Data JPA, Hibernate ORM, and auto schema generation.

🍃
Thymeleaf Templates

Server-side rendering with Thymeleaf fragments, layouts, and powerful expression language.

✅
Form Validation

Bean Validation with server-side error messages and user-friendly feedback.

🔍
Search & Filter

Real-time search and category filtering powered by custom JPQL queries.

🎨
Beautiful Design

Modern responsive UI with Bootstrap 5, custom CSS variables, and smooth animations.

🏗️
Clean Architecture

Layered architecture with Controller, Service, Repository, and Model separation.
